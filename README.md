# Subscription Tracker

A sleek, minimal, and secure application to track, manage, and optimize your monthly recurring subscriptions and personal expenses.

## 🚀 Features

*   **Visual Dashboard:** Clean analytics displaying your total monthly and annual subscription spend.
*   **Smart Notifications:** Get alerted before a subscription automatically renews or increases in price.
*   **Category Tagging:** Organize your subscriptions by categories (e.g., Entertainment, Utilities, SaaS, Health).
*   **Currency Support:** Track and convert multi-currency subscriptions seamlessly.
*   **Privacy First:** Secure data handling to ensure your financial logs stay private.

## 🛠️ Tech Stack

*   **Frontend:** React / Next.js (or Flutter / Swift for Mobile)
*   **Backend:** Node.js / Express (or Python / FastAPI)
*   **Database:** PostgreSQL / MongoDB

## 📦 Installation & Setup

Follow these steps to get a local copy up and running:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/subscription-tracker.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd subscription-tracker
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Set up environment variables:**
   Create a `.env` file in the root directory and add your configurations (e.g., database URI, API keys).

5. **Start the development server:**
   ```bash
   npm run dev
   ```
